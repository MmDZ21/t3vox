# Code of Conduct

## Our Standards

This project welcomes respectful, inclusive, and technically focused collaboration. Participants are expected to communicate constructively, assume good faith, and help others learn.

Examples of encouraged behavior:

- Giving and accepting constructive feedback
- Focusing on what is best for the community and the codebase
- Showing empathy toward other contributors

Examples of unacceptable behavior:

- Harassment, discrimination, or hateful conduct of any kind
- Threats, intimidation, or personal attacks
- Doxxing or publishing private personal information without consent
- Publishing credentials, identity exports, or other secrets
- Attacks on third-party servers, networks, or services
- Impersonation of maintainers, contributors, or TeamSpeak staff

## Maintainer Responsibilities

Project maintainers may edit, remove, reject, lock, or ban interactions that violate this code. Maintainers are responsible for clarifying standards and may take corrective action when appropriate.

## Scope

This code applies to all project spaces, including:

- GitHub issues and pull requests
- Code reviews and review comments
- Discussions and wikis
- Any other channels where this project is represented

## Enforcement and Reporting

Report conduct concerns through a **private channel** appropriate to the platform:

- For security-sensitive evidence (credentials, identities, exploit details), follow [SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting or a private Security Advisory.
- For other conduct concerns, contact maintainers through GitHub private messaging or request a private discussion thread without posting sensitive details in public.

All reports will be reviewed and investigated. Maintainers are obligated to respect reporter privacy where possible.
